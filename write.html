What is worth keeping?

It can be polished, unfinished, important, ridiculous, academic, sentimental, or completely random.

Drafts save only on this device. Finished archive pieces live as Markdown files in the GitHub repository.

How this fits

One place, different kinds of things.

Use Thought for fragments and observations, Memory for things you want preserved, Writing for essays and finished pieces, Learning for school or rabbit holes, Idea for things you may build later, and Collection for recipes, lists, books, or anything else.

You do not have to organize perfectly. Tags are allowed to be messy.
